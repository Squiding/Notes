# Machine Learning Book Recommendations

## Classic and Foundational Books

### 1. Probabilistic Machine Learning Series
- **Author**: Kevin P. Murphy
- **Books**:
  - *Probabilistic Machine Learning: An Introduction*
  - *Probabilistic Machine Learning: Advanced Topics*
- **Note**: A comprehensive series covering both fundamental and advanced topics in probabilistic machine learning.

### 2. Information Theory, Inference, and Learning Algorithms
- **Author**: David J.C. MacKay
- **Year**: 2003
- **Link**: [Book Website](https://www.inference.org.uk/mackay/itila/book.html)
- **Note**: A classic text that approaches machine learning from an information theory perspective. Despite being published in 2003, many of its insights remain highly relevant today.

## Statistical Learning Foundations

### 3. Foundations of Machine Learning
- **Author**: Mehryar Mohri, Afshin Rostamizadeh, and Ameet Talwalkar
- **Note**: A comprehensive introduction to the theoretical foundations of machine learning.

### 4. Understanding Machine Learning: From Theory to Algorithms
- **Author**: Shai Ben-David and Shai Shalev-Shwartz
- **Note**: A detailed exploration of machine learning theory and algorithms.

### 5. Statistical Learning Theory
- **Author**: Percy Liang
- **Link**: [Lecture Notes](https://web.stanford.edu/class/cs229t/notes.pdf)
- **Note**: Excellent lecture notes covering statistical learning theory.

## High-Dimensional Statistics and Probability

### 6. High-Dimensional Statistics: A Non-Asymptotic Viewpoint
- **Author**: Martin J. Wainwright
- **Note**: Focuses on high-dimensional statistics, particularly useful for understanding bounds and theoretical guarantees.

### 7. High-Dimensional Probability: An Introduction with Applications in Data Science
- **Author**: Roman Vershynin
- **Note**: Provides a comprehensive introduction to high-dimensional probability with applications in data science.
